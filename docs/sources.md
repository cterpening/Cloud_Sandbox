## Freshness policy

- Recheck a sandbox profile before using it for a new verification run.
- Review high-use profiles at least quarterly once the project is active.
- Treat a changed source page as requiring human review.
- Do not automatically convert marketing language into a capability claim.
- Preserve the previous profile in Git history when limits change.
- Add release/service-version sources inside the relevant lab rather than expanding this file indefinitely.
