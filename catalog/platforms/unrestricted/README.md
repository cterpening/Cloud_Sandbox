# Unrestricted or Personal Cloud Profiles — Planned

An unrestricted profile is not literally unrestricted. Personal subscriptions still have budget, quota, regional capacity, identity, policy, and provider-registration constraints.

Future personal or production-oriented profiles should therefore be explicit about:

- Maximum acceptable cost and resource lifetime.
- Allowed regions.
- Current quotas.
- Identity and workload-federation expectations.
- Private-networking requirements.
- Required cleanup and budget alerts.
- Whether the profile is safe for unattended CI.

No personal subscription identifiers or credentials belong in this repository. User-specific values should remain in ignored local variable files.
