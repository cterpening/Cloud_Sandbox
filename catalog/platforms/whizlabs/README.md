# Whizlabs Profiles — Planned

Whizlabs advertises open cloud sandboxes and certification-oriented hands-on environments for Azure, AWS, and GCP. Public descriptions establish broad categories of available services, but this repository does not yet have a sufficiently precise, current limit table for compatibility decisions.

Before adding JSON profiles:

1. Locate authoritative current service, quota, region, permission, duration, and persistence documentation.
2. Distinguish the open sandbox from guided and certification-specific labs.
3. Run a safe, sanitized capability check when documentation is incomplete.
4. Record observed behavior separately from advertised capability.
5. Avoid copying proprietary lab instructions or assessment content.

Starting references:

- [Whizlabs Azure Sandbox](https://www.whizlabs.com/azure-sandbox/)
- [Whizlabs: Hands-on Labs vs. Sandbox](https://www.whizlabs.com/blog/hands-on-labs-vs-sandbox/)
